# Amharic Charades

A fun, culturally relevant Charades/Heads-Up game built natively for Android. Play with friends and family using Amharic words, proverbs, and pop culture references!

![App Icon](app/src/main/res/mipmap-xxxhdpi/ic_launcher.png)

## 🎮 Features

*   **7 Unique Categories:**
    *   🦁 **Animals** (እንስሳት)
    *   🎬 **Movies & TV** (ፊልሞች እና ድራማዎች)
    *   📚 **Literature** (ስነ-ጽሁፍ - Books & Authors)
    *   🏔️ **Places** (ቦታዎች - Landmarks & Cities)
    *   🌟 **Celebrities** (ታዋቂ ሰዎች)
    *   📜 **Proverbs** (ተረቶች - Amharic Proverbs)
    *   🔀 **Random Mix** (ቅልቅል - All categories combined)
*   **Sensor Controls:** Tilt your phone **DOWN** for Correct, **UP** to Pass.
*   **Touch Fallback:** Invisible touch zones for playing without tilting.
*   **Dark Mode Support:** Fully optimized UI for night-time play.
*   **Customizable Settings:** Change round duration (60s, 90s, 120s) and toggle sound effects.
*   **Sound Effects:** Custom audio cues for correct/pass answers.

## 📱 How to Play

1.  **Pick a Category:** Choose from the main menu grid.
2.  **Get Ready:** Hold the phone against your forehead so your friends can see the screen, but you can't.
3.  **Guess:** Your friends act out, sing, or describe the word.
4.  **Tilt or Tap:**
    *   Got it right? **Tilt Phone DOWN** (or tap left screen).
    *   Want to pass? **Tilt Phone UP** (or tap right screen).
5.  **Score:** Review your results and see which words you missed at the end of the timer!

## 🛠️ Tech Stack

*   **Language:** Java
*   **UI:** XML (Material Design Components)
*   **Architecture:** MVC Pattern
*   **Sensors:** Android `SensorManager` (Accelerometer) for tilt detection.
*   **Persistence:** `SharedPreferences` for game settings.
*   **IDE:** Android Studio
*   **OS:** Developed on CachyOS (Arch Linux).
